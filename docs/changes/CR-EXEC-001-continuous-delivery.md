原规则：V1.0 自主执行规则的 L3 事项和正式 Gate 要求人工作出逐项确认；总控 V1.1 与仓库约束禁止未经逐项确认改变锁定方案。

边界：不向外部发送客户正文/密钥，不提交 Secret，不能代替客户签署，不能代购或消耗额度重置，不能强推覆盖远端，不能做不可恢复生产操作。若客观环境缺失则记录未验证并继续可执行部分。

回滚：可恢复旧执行纪律，但已发生的 Change Request、测试与提交历史保留；不得追写原冻结提交。
