# CR-PKG-007 原生 OCR 许可文本加入新非发行候选

日期：2026-10-01；状态：`RECORDED / NEW_CANDIDATE_INTEGRITY_PASS / RELEASE_REVIEW_OPEN`。关联 P45-A01/A02、固定 P43 候选 SHA-256 `764d2f84c8da9fa8a58a521026502f397dcb0602a3e48e9ac702c8e95a9cb7a5` 和 34 项原生 PE 矩阵。原冻结架构/API/Schema 及 P43 历史 ZIP 不追写。

## 差异与方案

P43 包含 34 个已核字节的原生 OCR PE，但没有对应组件的专属许可通知侧载；本地矩阵的 61 条许可文本已从精确原始包/上游源码归档核对，得到 42 个不同正文 SHA。保留旧包仅附本地路径不能满足离线候选的材料可获得性；把 61 条重复正文各自复制会增加重复字节，也不自动解决适用性审查。

选择在**新的** `NOT-FOR-RELEASE` ZIP 中增加 `payload/third-party-licenses/native-ocr/texts/{sha256}.txt` 的 42 份原文、逐二进制/来源的 61 条机读映射及明确的审阅说明。映射记录源归档、成员、正文 SHA 与目标 PE，但不把矩阵的 `release_obligations_reviewed=NO` 改成通过，不把共享正文推定为法律适用结论。P43 原 21,114 项载荷逐件不变；预期新增 44 项，顶层 manifest、hash 清单与库存只作相应非发行声明更新。

## 风险、迁移、回滚与验证

风险：哈希命名正文不适合直接面向用户阅读；必须同时提供可读的组件映射和说明，最终产品 LICENSE/NOTICE 仍由合格人员复核。部分许可证要求不仅是附正文，还可能涉及归属、对应源码、构建补丁与组合分发条件；本 CR 不对这些作法律判断。新侧载不得包含客户资料、密钥或本地绝对路径。

无业务运行、数据库、API、权限、依赖、SCM 或正式安装变化；无需 Migration。失败时弃用新 ZIP，保留固定 P43 及其历史证据。构建前重验 P43/P33/P22、34 项二进制及 61 条源字节；构建后独立核新 ZIP 全量清单、42 正文哈希、61 映射、原 21,114 项逐件不变、所有发行门禁继续 false，再做清洁解包。任何验证失败不提升发行。正式法律、产品 NOTICE、信任源、Server 2025 与 Gate/UAT 仍分别开放。
