# DOC-03-A03-P03 文件完整性校验与受控发布

日期：2026-09-25。版本：`0.1.0.dev0`。状态：内部命令与合成验证 PASS；未对外开放。

## 本次完成

- 对已授权、Scope/Project 匹配、`PERSISTENT` 且版本匹配的 `STAGED` FileObject，要求数据库已有 UUID 派生暂存定位符、32 字节 SHA-256、非负大小与检测 MIME。
- 以配置的单次字节上限流式校验暂存文件的大小与 SHA-256，拒绝重解析点、非普通文件、硬链接源及校验期间可检测到的变化；同卷无覆盖提升，再校验正式文件。
- 在发布后的独立数据库事务中行锁复核，原子更新 `AVAILABLE`、正式定位符、版本和时间，并写状态事件、Audit、幂等收据。按同一 Key 重放返回原事件，异载荷拒绝。
- 使用 Windows 11 合成文件及 PostgreSQL 18 临时库核验正确发布、重复请求、跨项目/无权限、Hash 错误、审计失败回滚；后端全量测试 456 项无失败，2 项符号链接场景因当前账户权限跳过；开发 wheel 构建 PASS。

## 界限与下一步

文件系统与 PostgreSQL 不能原子提交。数据库/Audit 失败后，正式文件可已存在而数据库仍是 `STAGED`；本项故意不盲删文件，也不声称自动恢复。下一项先实现 DOC-03-A03-P04 受控发布恢复/隔离，再实现 DOC-02 内部版本提交协调。当前没有正式 Document 权限适配、上传文件类型/特征校验、公开 HTTP、下载或生产信任源。合成 MIME 仅由数据库元数据提供，不等于已通过真实内容类型检测。Server 2025 与 Debian 13 未验证，Gate 3 和可用程序包未达成。

## 兼容与升级

无新依赖、公开 API 或 Migration。目标数据库仍需按既有流程备份并升级至 `20260925_0022`；本次仅在内部显式装配时可调用。撤回可停止装配，但已发布元数据与历史不可删除/倒写；孤立正式文件按后续恢复矩阵处理。
