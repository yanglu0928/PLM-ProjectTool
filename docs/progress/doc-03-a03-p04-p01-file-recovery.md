## 范围与结果

依据冻结 DM-03 的崩溃恢复矩阵，只处理明确指定、已受权的 FileObject：数据库仍为 `STAGED`，暂存文件已经消失，最终文件存在且独占。恢复先以数据库的相对定位符、SHA-256、大小及单次上限重校验最终字节，再在短数据库事务内行锁复核 Scope/Project、版本和元数据，原子写入 `AVAILABLE`、状态事件、Audit、幂等收据。恢复操作使用独立于普通发布的幂等作用域；同 Key 返回原事件，异载荷拒绝。
