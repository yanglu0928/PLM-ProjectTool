# CR-DOC-008/A03-P02-A01：已登记 Abort 文件单路径清理适配

- 日期：2026-09-26；结果：Windows 11 临时数据根文件侧适配 PASS；尚无数据库编排或生产入口。
- 决策：`DEC-20260926-133`。适配器每次只删除一个当前身份与 Hash/大小完全吻合的路径：`STAGE_ONLY` 删除暂存，`FINAL_VERIFIED` 删除最终文件，`LINKED_PAIR` 先删除暂存、下一次再删除剩余最终文件；`NONE` 仅报告缺失供上层崩溃对账。双路径无关、重解析/额外硬链接、损坏内容或身份替换均拒绝。
- 调用前置：上层必须持同一上传 ID 的 OS 栅栏，并在数据库中证明 ABORTED/CLEANUP_PENDING、零正式引用、无保留限制。此文件适配器自身不提供权限或 Audit，不得单独用于真实已登记正文。
- 验证：6 项新增单元测试在临时数据根覆盖三种可恢复形态、逐步重试、无关双文件、损坏、额外硬链接和 Hash 后同内容换 inode 的拒绝。后端全部 559 项无失败（2 项既有符号链接环境跳过），开发 wheel PASS；无 PostgreSQL 删除联动验证。无 Migration、公开 API 或新依赖；版本 `0.1.0.dev0`。
- 下一项：A03-P02-A02 建立先审计请求、逐路径清理、缺失对账、最终 FileObject `REMOVED`/事件/Audit 同事务的内部编排；正式生产清理继续关闭，直到旧版进程停写及目标账户演练通过。
