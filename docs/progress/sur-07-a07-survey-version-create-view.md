在调研定义详情增加受权创建入口。新页面展示当前合格交接问题候选及其固定版本定位，选择的是版本内行 ID 而非公开业务问题 ID；支持分页读取、目标 ACTIVE 部门、多问题卡片和六种回答形式。实际面对面访谈记录优先；没有固定来源时只能显式填写 `MANUAL` 访谈来源说明，不将业务表单或 AI 建议伪装成客户事实/已批准交接引用。客户端在提交前重验完整快照，服务端仍是唯一最终资格判定者。

结果不明时本地保留原问题快照、强 ETag 和操作号，须核对版本列表后显式原号重试；损坏记录或幂等冲突锁定，不自动换号。当前会话失去写资格时清除页面中的项目内容和入口。仅发送本项目受权命令，无客户资料外发第三方。

验收：页面定向6项，连同现有详情/客户端定向16项；前端全量192文件、2037项，通过；TypeScript 检查和 Vite build 退出0。首轮增加会话变化测试时复用已消费的模拟 HTTP 回执、后又误查不存在按钮，均为测试夹具断言问题，已修并完整复验。Vite 仍提示主包大于500 kB，作为既有性能/分包事项保留。尚无真实 Edge/HTTPS/PG 调研版本写链或固定包证据。
