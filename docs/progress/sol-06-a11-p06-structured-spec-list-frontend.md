# SOL-06-A11-P06：结构化专项历史列表页面

- 日期/版本：2026-10-16 / `0.1.0-dev.0`。TraceLink：冻结 `SOL_SPEC_LIST` → A11-P05 Windows HTTP/PG → 本项。当前 Phase 2。
- 编码前检查：A11-P05 已通过 Windows 显式模式与真实 HTTP/PG；现有章节历史页、专项详情页和项目导航提供可复用模式。本项仅新增只读客户端、页面、路由和导航，不改 Schema、冻结 API、角色、License 权益、写入语义或依赖。
- Changed：新增项目级“结构化专项版本”页面，从项目详情、创建页和详情页可进入或返回；项目成员可读取不可变最小摘要、加载更早版本并进入精确固定版本详情，项目负责人/实施成员可见创建草案入口。四类专项和六种版本状态显示中文提示，明确 DRAFT、历史引用或出现在列表中均不等于批准、仍合格或客户确认。项目切换、分页异常或后续页失败时清除旧/部分内容。
- 安全边界：新增客户端严格核对项目身份、字段集合、类型/状态、UUID、指纹、评审字段配对、版本前驱、时间、UUID 降序、签名游标、trace/no-store 和安全错误映射；默认 `fetch` 使用浏览器绑定包装，避免 Edge `Illegal invocation`。列表不接收或展示 payload/ref 正文。
- 验证：客户端、列表页、详情/创建回链和项目入口联合定向 `5 files / 34 tests`；前端全量 `143 files / 1794 tests`；TypeScript/Vue 类型检查和 Vite 生产构建通过，生成独立列表页面资源。
- 验证偏差：首次定向运行发现 Vue SFC 中跨行对象类型断言无法解析，改为显式类型局部变量；第二次运行发现同一内存路由在卸载后复用于另一挂载导致测试参数丢失，改为每个挂载独立路由。修复后定向及全量均通过，未改变产品权限或安全约束。
- 兼容性/升级/回滚：无 Migration、后端/冻结 API、依赖或旧数据变化；部署新静态资源即可升级，撤回路由、页面、客户端和导航可回滚，后端历史保留。Windows Server 2025/Debian 13 未实测。
- 限制：尚未以 Windows 11 Edge 连接真实 HTTP/PG 验证列表、分页和详情导航；正式服务账户、公钥、License 与游标密钥信任仍未验。专项修订/验证/送审、OutputArtifact、章节六维、Gate 3/Pilot/正式 Release 仍待。
