# SOL-06-A09-P06-P03：结构化专项创建浏览器验收

- 日期：2026-10-12
- 范围：Windows 11、Edge、隔离且可弃的 PostgreSQL 18.6、合成项目/账户/License；不使用客户资料，不向 AI 厂商发送数据。
- 编码前检查：P06-P01 客户端、P06-P02 页面、P05 Windows 显式写模式、冻结 SOL_SPEC_CREATE 合同和可弃浏览器夹具均已就绪。此 WBS 只解决真实浏览器创建/重放与其暴露的同项目待决恢复缺陷，不修改冻结 API、Schema 或安全策略。

## 实施及偏差

- 扩展现有浏览器夹具的可选专项模式，装配受权候选读取、章节列表及 SOL-06 CREATE；保留原章节创建验收路径。
- 新增专项 Edge 脚本：登录合成账户、读取当前候选、提交类型化流程草案、检查首次 201，并以同一正文和操作号重放。切换到另一项目时，页面不展示前一项目的待决输入。
- 首次运行发现验收夹具遗漏章节列表路由，补齐后再次运行。再次运行暴露同一项目离开/重进时待决操作未恢复：原页面只监听 projectId，而路由名称变化不触发恢复。已让页面同时监听路由名称与 projectId，并增加单元回归。这是页面级缺陷修复，无合同偏差；不把浏览器测试失败隐藏为通过。
- 数据库核对仅新增一份专项 DRAFT、一条对应的持久幂等收据及一条 Audit；原号重放未二次写入。
