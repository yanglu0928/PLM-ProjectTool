- 当前 Phase：Phase 2 Platform Core
- 当前 WBS：POC-03-G3-A01（Gate 3 新独立留出集本地预检工具）
- 输入基线：ADR-009、POC-03 留出集 Schema、Gate 2 冻结基线；不变更质量阈值。
- 前置任务：旧 50 条真实复验完成且失败证据保留；本任务不需要新的客户数据外发。
- 涉及模块：POC-03 评测辅助工具，不进入生产 API/业务模块。

- 验收标准：至少一个历史集；拒绝复用问题、ChunkId、同文档定位和正文 Hash，同批 CaseId 不得重复；输出仅计数/布尔值/文件哈希，不写客户正文；合成正反测试通过。跨批 CaseId 可从 `HO-0001` 重启，不视为证据重用。

本任务不重新使用旧 50 条作为独立质量结果，也不发起百炼/DeepSeek 调用。真实新留出集的采样、人工确认与逐轮外发授权仍为后续独立任务。
