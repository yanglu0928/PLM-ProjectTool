# DOC-01-A05-P06 下载断线与部署容量边界

- 日期：2026-09-26；结果：Windows 11 官方单进程入口的中断清理/配置边界 PASS；生产磁盘容量与多实例场景未验收。
- 决策：`DEC-20260926-132`。Windows 官方启动入口显式 `workers=1`；下载 Router 每进程最多四个并行快照、每个至多 100 MB，因此单入口下载快照的理论磁盘上界为 400 MB（内存阈值 1 MiB/快照，超过后可能转磁盘）。这不是数据卷剩余空间保证，其他上传/任务/实例也会占空间。
- 验证：在 ASGI 发送非空正文时模拟客户端断开，发送异常后私有文件关闭，下一下载可重新获取名额；原有正常/异常读取测试保留。Windows 启动组合合同检查单工作进程参数。后端 541 项无失败（2 项既有符号链接环境跳过）；开发 wheel PASS。
- 无 Migration、冻结 API 修改或新依赖。版本 `0.1.0.dev0`。
- 已知问题：未在真实网络层做客户端断线压力测试，也未测试多实例共享数据卷、磁盘耗尽与正式目标账户。多实例部署前须按实例数 × 400 MB 加上传/任务临时空间做容量评估、监测及实际压测；此项不能替代 Release Gate。
