## 脱敏诊断

1. 分类失败不能归因于检索缺失：114 条精确召回样本中分类正确 49 条；6 条检索未命中样本中分类正确 2 条。
2. 47 条期望 `INSUFFICIENT_INFORMATION` 中只有 14 条正确，30 条被判为 `STANDARD_SATISFIED`；6 条期望 `NON_STANDARD` 全部未命中，其中 3 条判为部分满足、3 条判为标准满足。
3. 预测分布为标准满足 60、资料不足 32、部分满足 19、无可靠匹配 9、非标准 0；Prompt v2 虽加强充分性 Gate，仍无法从当前抽取式问题中稳定推导人工业务标签。
4. 本地抽样显示，多条问题只要求从资料中摘录“采用何种实现方式/有哪些约定”，没有表达要判断标准满足、部分满足或非标；相同问法在 Golden 中分布于不同标签。为追求 90% 而加入标签分布、单条关键词或 case 规则会形成测试集泄漏。
5. R5 已把期望 Chunk 放入 Top-5 的样本为 114 条，但模型只选择 62 个唯一期望 Chunk。部分同文档相邻或等价片段仍按错误计数；是否扩展为可接受引用集合属于 Golden 基线变更，不能由 AI 自行处理。

## 保持不变的边界

- 未降低 90% / 98% 门槛，未修改 R6 标签、问题或期望引用。
- 未把 Golden 标签、期望答案、期望 Chunk 或审核信息发送给模型。
- 未把查询、Context、向量、逐条响应或 case-level 结果提交到 Git。
- 未调用百炼 Embedding 或 Reranker；脱敏汇总明确记录两类当前轮外部调用为 0。
