# RAG-04-A06-P06 Windows composition validation

Runs an isolated Windows 11/PostgreSQL 18.6 proof for the explicit Retrieval
policy, dedicated query-content key, production HTTP composition, shared cancel
Owner, and the fair bounded Retrieval family inside `AI_PROVIDER_WORKER`.

The fixture uses synthetic text and an in-memory validation key resolver. It
does not provision or export a real Vault key and performs no Provider network
I/O. A successful run prints
`RAG_04_A06_P06_WINDOWS_COMPOSITION_PASS`.
